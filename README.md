# 🛒 Что выгоднее

**Сравнение цен за килограмм, литр или штуку.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/price-compare/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Любое число вариантов
- Мультипаки (3 × 200 г) и скидки
- Подсветка самого выгодного и переплата в процентах
- Примеры и автосохранение

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/price-compare.git
cd price-compare
python3 -m http.server 8000
```
